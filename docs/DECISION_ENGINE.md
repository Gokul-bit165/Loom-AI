# Loom-AI Decision Engine Specification

## 1. Core Mathematical Formulations

### 1.1 Efficiency & Utilization Split
```
loom_efficiency_pct = (actual_picks / (std_rpm * scheduled_minutes)) * 100
performance_eff_pct = (actual_picks / (std_rpm * running_minutes)) * 100
utilization_pct     = (running_minutes / scheduled_minutes) * 100

Identity:
loom_efficiency_pct ≈ (performance_eff_pct * utilization_pct) / 100
```

### 1.2 Warp & Weft Extra Timing Analytics (Q2)
```
extra_warp_time_min = max(actual_warp_time_min - standard_warp_time_min, 0)
extra_weft_time_min = max(actual_weft_time_min - standard_weft_time_min, 0)

production_loss_metres = ((extra_warp_time_min + extra_weft_time_min) * std_rpm) / picks_per_metre
revenue_loss_rs        = production_loss_metres * selling_rate_per_metre
```

### 1.3 Transparent Loom Performance Score (Q3)
Instead of a single blind ranking, the system provides:
- **Output Leader**: Ranked by total metres / kilo-picks produced.
- **Efficiency Leader**: Ranked by `loom_efficiency_pct`.
- **Composite Performance Score (CPS)**:
```
CPS = (0.40 * Norm(Efficiency)) + (0.30 * Norm(Utilization)) + 
      (0.15 * Norm(1 - BreakRate)) + (0.15 * Norm(TargetAchievement))
```
Formula is published transparently on the dashboard.

### 1.4 Breakdown Anomaly & Baseline Detection (Q6)
For each loom $i$, compare current daily downtime $D_i$ against its 30-day baseline distribution $(\mu_{30d}, \sigma_{30d})$:
```
anomaly_score = (D_i - μ_{30d}) / max(σ_{30d}, 1.0)
is_anomalous  = anomaly_score > 2.0  (i.e. > 2 standard deviations above baseline)
```

### 1.5 Mutually-Exclusive Revenue Loss Attribution Waterfall (Q23)
To prevent double-counting:
```
Potential Maximum Revenue (at 100% capacity)
  ├── 1. Breakdown Loss (Mechanical & Electrical stops from stop_events)
  ├── 2. Electrical / Utility Loss (Grid & voltage fluctuation stops)
  ├── 3. Low-Speed / Efficiency Loss (Picks lost while running below standard RPM)
  └── 4. Quality Rejection Loss (Off-spec metres × downgrade discount)
  = Realized Net Revenue
```

### 1.6 Manpower Shortage Production Impact (Q10)
```
shortage_hours = max(required_weavers - present_weavers, 0) * shift_scheduled_hours
unattended_loom_hours = shortage_hours * standard_looms_per_weaver
lost_metres = unattended_loom_hours * 60 * std_rpm / picks_per_metre
```

### 1.7 Air Consumption & Financial Leakage (Q15-Q17)
```
excess_cfm_per_loom = max(actual_cfm - standard_cfm, 0)
total_excess_cfm    = sum(excess_cfm_per_loom)
power_loss_kwh      = (total_excess_cfm / 4.5) * running_hours   # ~4.5 CFM per kW compressor rule
financial_air_loss  = power_loss_kwh * cost_per_kwh
```

## 2. Structured Recommendation Generation & Prioritization

Every diagnostic recommendation is created through a deterministic rule pipeline:

```json
{
  "recommendation_id": "REC-ATM-20260731-01",
  "priority": "P1",
  "category": "ELECTRICAL",
  "loom_id": 118,
  "loom_no": "AJ-118",
  "issue": "High recurrence electrical downtime on AJ-118",
  "metrics": {
    "downtime_min": 509,
    "events_count": 10,
    "efficiency_pct": 74.2,
    "baseline_downtime_min": 210,
    "anomaly_multiplier": 2.4
  },
  "evidence": [
    "509 min total downtime today (2.4x 30-day baseline of 210 min)",
    "10 distinct voltage fluctuation stop events logged in Shift 1 and Shift 2",
    "Estimated production gap: 125 kg"
  ],
  "probable_cause": "Unstable inverter drive voltage supply or loose terminal contact at Loom AJ-118 sub-panel.",
  "recommended_action": "Immediate electrician inspection of AJ-118 main busbar voltage, inverter drive capacitors, and earth continuity.",
  "expected_impact": {
    "production_recovery_kg": 125,
    "revenue_recovery_rs": 37500
  },
  "confidence": "HIGH",
  "status": "OPEN"
}
```

### Priority Matrix
- **P1 (Immediate Action)**: Safety risk, breakdown risk > 80%, or revenue loss > ₹20,000/shift.
- **P2 (Same Shift)**: Overrun maintenance, excessive air leakage > 30% standard, weaver attendance deficit.
- **P3 (Today / Next Shift)**: Crimp deviation, style tension tuning, yarn waste > 2.5%.
- **P4 (Monitor / Preventive)**: Mild speed efficiency drift (< 3% gap), scheduled PM within 3 days.

## 3. The Management Decision Workflow (Loop-Closing)
1. **OPEN**: Auto-generated by Decision Engine.
2. **ACKNOWLEDGED**: Floor supervisor / Manager reviews the evidence.
3. **ASSIGNED**: Task delegated to specific technician/weaver with target resolution timestamp.
4. **COMPLETED**: Floor action logged with fix notes and replacement parts.
5. **VERIFIED**: System monitors subsequent 24-hour telemetry to confirm metric recovery before marking verified.
